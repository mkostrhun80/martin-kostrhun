# Záloha mobilního tlačítka Obsah + rohového vějíře (quarter-pie)

Tato složka uchovává zálohu varianty mobilního ovládání s levým pilulkovým tlačítkem **Obsah** a rohovým skleněným vějířem (`Úvod`, `O mně`, `Služby`, `Spolupráce`, `Více`).

## Soubory
- `ScrollContents.tsx` — záloha komponenty `components/site/ScrollContents.tsx`
- `contents-rail.css` — záloha stylů `app/contents-rail.css`

Pro obnovení stačí tyto dva soubory zkopírovat zpět do `components/site/ScrollContents.tsx` a `app/contents-rail.css`.
